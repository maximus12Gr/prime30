ИИ для фото еды (бесплатно)

Нужен бесплатный ключ Gemini API. Подписка Google AI Plus тут не нужна — ключ из AI Studio бесплатный и без карты.
  1. Открой aistudio.google.com и войди в Google
  2. Слева «Get API key» → «Create API key»
  3. Скопируй ключ и вставь сюда
Ключ хранится только на этом телефоне и не попадает на GitHub. На бесплатном тарифе Google может использовать фото для улучшения моделей — не фоткай ничего личного.
